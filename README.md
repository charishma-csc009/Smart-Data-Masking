# Smart Data Masking System

A robust security application designed to protect Personally Identifiable Information (PII) across multi-database environments with dynamic Role-Based Access Control (RBAC).

## 🚀 Features
* **Automated PII Detection:** Scans and identifies sensitive data fields (e.g., emails, phone numbers, SSNs).
* **Dynamic Masking:** Automatically masks sensitive records based on the user's role (Admin vs. Support vs. Analyst).
* **Multi-Database Support:** Seamless integration and handling across databases (SQLite, MySQL, PostgreSQL).
* **Interactive Dashboard:** Easy-to-use interface for managing policies and viewing masked outputs.

## 🛠️ Tech Stack
* **Backend:** Python, Flask
* **Frontend:** HTML, CSS, JavaScript (or React/Streamlit depending on your stack)
* **Database Management:** SQLite / SQLAlchemy
